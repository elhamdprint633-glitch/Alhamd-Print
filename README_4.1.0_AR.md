# الحمد برنت — الكمبيوتر 4.1.0 والموبايل 2.0.0

## التحديث مع الحفاظ على البيانات

احفظ نسخة احتياطية، ثم أغلق البرنامج وثبّت setup.exe فوق النسخة الحالية: Next → Next → Install → Finish. احتُفظ بمعرّف التطبيق ومسار البيانات واسم الملف التنفيذي وإعداد عدم حذف بيانات التطبيق عند الإزالة. لا تصفّر البيانات ولا تحذف النسخة السابقة يدويًا. المُثبت يشمل Windows x64 وARM64.

ثبّت APK فوق تطبيق العرض السابق المسلّم من نفس الحزمة والتوقيع. رقم الحزمة eg.alhamd.print.viewer، ورمز الإصدار الجديد 20000. الربط المحلي السابق يُقرأ، ولا تحتاج إزالة التطبيق. لضم عنوان الإنترنت إلى ربط محلي قديم بلا معرّف كمبيوتر، حدّث الكمبيوتر ثم أعد اعتماد الربط المحلي برمز جديد أولًا.

## تصميم الفاتورة

1. ادخل بحساب المدير، ثم «إعدادات الفاتورة ← تصميم الفاتورة ← فتح مصمم الفاتورة».
2. اختر قالب ألوان الحمد أو الأزرق المهني أو الأبيض والأسود، أو أنشئ قالبًا جديدًا. «تحميل القالب المختار» يحمّله للمراجعة؛ «حفظ وتطبيق» يعتمده في البرنامج.
3. حدد الشعار أو العنوان أو رقم المستند أو أي عنصر من الورقة أو الطبقات. اسحب لتحريكه، واسحب المربع الأخضر لتغيير حجمه، أو أدخل الأبعاد بالملليمتر. توجد شبكة محاذاة وتكبير وتصغير وتراجع وإعادة.
4. أضف نصًا ثابتًا، صورة، خطًا، أو حقولًا مرتبطة باسم المطبعة والعنوان والهاتف والتاريخ والعميل والإجماليات. الأرقام المرتبطة تقرأ من المستند، ولا تُحرّر من المصمم. العناصر الحرة في رأس المستند وتذييله؛ جدول البنود يتمدد تلقائيًا، والملخص المالي يبقى مرة واحدة في النهاية لتجنب التداخل والقص.
5. خصص ورق A4 أو A5 واتجاهه، الخطوط والألوان والحدود والصفوف والمسافات وموضع الملخص، والعلامة المائية. رتّب الأعمدة وأظهرها أو أخفها وحدد أوزان عرضها. إعدادات إخفاء العميل والهاتف والأقسام المالية تظل محترمة.
6. راجع فاتورة تجريبية وكشف حساب وفاتورة طويلة قبل الاعتماد. إذا كان النص أطول من العنصر كبّر المساحة أو صغّر الخط. عند تفعيل قالب، تكون ألوانه وخطوطه وعلامته المائية من المصمم. قوالب المصمم تطبق على مستندات الكمبيوتر المتصلة بمحرك الفواتير: البيع والشراء والخدمات والمسحوبات وكشوف الحساب، في المعاينة والطباعة وPDF والصور.
7. «تصدير القالب» ينتج JSON لتشاركه، و«استيراد قالب» يقرأه. توجد ملفات أمثلة مرفقة. لا يقبل المصمم PSD أو HTML أو أكوادًا قابلة للتنفيذ، ولا صورًا من روابط خارجية. ملفات التصميم لا تشمل بيانات العملاء أو الحسابات. «التصميم الأصلي» يرجع للعرض السابق دون حذف القوالب أو تعديل المعاملات.

لم يُغير التحديث طريقة احتساب الأرصدة والخصومات والمقاصة أو الخزينة أو المخزون. تسجيل المعاملات ما زال من الكمبيوتر وحده. تطبيق الهاتف يحتفظ بمحرك مشاركة مستنداته المحلي الحالي؛ مصمم الفواتير في هذا الإصدار خاص بمستندات الكمبيوتر.

## كيف يعمل الربط دون خدمات خارجية؟

لا توجد استضافة أو Tailscale أو Cloud أو خدمة وسيطة. برنامج الكمبيوتر نفسه يقدم نسخة عرض للهواتف المعتمدة. يجب أن يبقى الكمبيوتر مفتوحًا، مستيقظًا، والبرنامج يعمل. يحتاج الوصول من خارج المطبعة عنوان IPv4 عامًا قابلًا للوصول وتحويل منفذ في الراوتر. وجود البرنامج متصلًا بالإنترنت وحده لا يكفي خلف CGNAT أو منفذ محجوب.

### داخل المطبعة — شبكة محلية

افتح «ربط الموبايل» على الكمبيوتر، ثم في الهاتف اختر «شبكة محلية»، واكتب IP الكمبيوتر والمنفذ 47821 ورمز الربط ذي 8 رموز. استخدم شبكة خاصة موثوقة فقط للربط المحلي التقليدي عبر HTTP. لا تفتح المنفذ 47821 للإنترنت.

### خارج المطبعة — إنترنت مباشر مشفر

1. اسأل مزود الإنترنت عن IPv4 عام قابلًا للوصول، ويفضل ثابتًا. عند CGNAT يلزم أن يغير المزود نوع العنوان؛ لا يمكن للبرنامج تجاوز ذلك دون وسيط، وقد رفض صاحب البرنامج أي خدمة خارجية.
2. ثبّت IP الكمبيوتر داخل الشبكة بحجز DHCP في الراوتر.
3. من «ربط الموبايل ← إعداد الاتصال المباشر المشفر» أدخل IP العام والمنفذ الخارجي (الافتراضي 47822)، ثم شغّل الربط. اختَر التشغيل مع فتح البرنامج إذا رغبت.
4. في الراوتر حوّل منفذ TCP الخارجي المختار إلى IP الكمبيوتر الداخلي، المنفذ 47822. اسمح لهذا المنفذ ولتطبيق الحمد برنت في جدار حماية Windows. لا يُغيّر البرنامج إعدادات الشبكة أو الراوتر أو الجدار تلقائيًا.
5. في الهاتف اختر «إنترنت مباشر HTTPS»، وأدخل العنوان والبصمة SHA-256 ذات 64 رمزًا ورمز الاعتماد المؤقت ذي 24 رمزًا من شاشة الكمبيوتر. قارِن البصمة من الكمبيوتر نفسه؛ ليست شهادة من جهة خارجية، بل اعتماد خاص بهذا الكمبيوتر. البصمة تحفظ مرة واحدة مع الربط.
6. اختبر عبر بيانات الموبايل، بعد فصل Wi-Fi. عبارة «الربط يعمل» على الكمبيوتر تعني تشغيل الخدمة فقط، ولا تثبت أن IP العام أو تحويل الراوتر متاحان. يتعذر إثبات إعداد اتصال المطبعة من بيئة البناء دون الوصول لشبكتها.

بعد حفظ العنوانين، يتأكد التطبيق أنهما لنفس الكمبيوتر. عند توفر Wi-Fi يحاول العنوان المحلي بتشفير وبصمة الربط المباشر أيضًا على المنفذ 47822، ثم العنوان الخارجي المشفر عند تعذر الوصول. لا يرجع إلى إرسال اعتماد الربط المباشر عبر HTTP. الجهاز المرتبط محليًا فقط يظل يستخدم المسار المحلي التقليدي على الشبكة الموثوقة.

يتحدث الهاتف تلقائيًا أثناء فتحه، ويتوقف الاستطلاع عند انتقال التطبيق للخلفية. بدون اتصال يعرض آخر نسخة محفوظة مشفرة مع وقتها، دون اختلاق تحديث أو تسجيل بيانات جديدة. يتطلب تغير IP العام تحديث عنوانه؛ لا يستخدم البرنامج DDNS أو خدمة لاكتشاف IP. إذا استُبدل الكمبيوتر أو تغيرت هويته، أعد الاعتماد بدل خلط بيانات جهازين.

«إيقاف الربط المحلي» لا يوقف المباشر والعكس. «إلغاء ربط كل الهواتف» يسحب الاعتماد للمسارين ويغيّر رموز الاقتران. المفاتيح الخاصة يحميها مخزن أسرار Windows؛ ليست ضمن ملفات القوالب أو نسخة العرض على الهاتف.

## ما تم التحقق منه وما لم يُختبر

- نجح 244 اختبارًا آليًا، تشمل الحسابات والمخزون والصلاحيات والتسويات والنسخ الاحتياطي، والقوالب والربط المباشر.
- نجحت تجربة واجهة المصمم: تحميله عند الطلب، تعديل الخصائص، الحفظ دون تعديل المعاملات، كشف حساب بجدول وملخص واحد، ومعاينة ضيقة دون قص اليمين.
- نجحت تجربة البرنامج الفعلي عبر Electron وSQLite وIPC: بيع وشراء ودفعات ومسحوبات وخصومات ومخزون، وحفظ PDF ونسخ الصور. نجحت تجربة قالب فعلي وحفظه في SQLite وPDF وصورة 300 DPI، دون اختلاف في البيانات المالية.
- نجح اختبار كود عميل الهاتف Java ضد خدمتي HTTP وHTTPS فعليتين داخل بيئة الاختبار: اعتماد المسارين، حفظ الملفين، تفضيل المحلي المشفر، التحويل للمباشر، رفض بصمة خاطئة وكمبيوتر مختلف، وقطع الوصول بعد سحب الاعتماد. استُخدمت بدائل لواجهات Android الخاصة باختيار الشبكة في هذا الاختبار؛ لا يُعد اختبار هاتف فعلي.
- جُمّع APK وتحقق توقيعه وتوافق الحزمة والإصدار، وفُحص CRC للمثبت وحمولتا x64 وARM64 ومطابقة ملفات التطبيق للمصدر.
- لم يُشغّل المثبت على Windows فعلي، ولم يجر اختبار هاتف Android فعلي أو إعداد راوتر المطبعة والوصول من الإنترنت العام. استُخدم مزود حماية مفاتيح تجريبي لاختبار Linux؛ Windows DPAPI نفسه لم يُختبر في هذه البيئة. المثبت غير موقع بشهادة ناشر تجارية. لا تعني الاختبارات ضمان انعدام كل عيب مع كل جهاز أو قاعدة بيانات.

ميزة واتساب داخل البرنامج مؤجلة؛ سلوك النسخ والمشاركة القائم لم يُستبدل.
